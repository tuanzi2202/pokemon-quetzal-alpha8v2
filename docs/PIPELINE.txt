--------
  .\build_all.ps1

等价步骤
--------
1. python tools/discover.py          （可选；已有 blacklists 时可跳过）
2. python tools/dump_text.py         （可选；已有 dump/ 时可跳过）
3. python tools/translate_batch.py dump/<bank>.jsonl
   或维护 locale/zh_CN/all_en_zh.jsonl（merge_locale_zh.py）
4. fontpatch\build.bat               （字模 + CharRead divert → work/cn_build.gba）
5. python tools/apply_text.py locale/zh_CN/all_en_zh.jsonl
6. python tools/force_ui_zh.py       （开始菜单等）
7. python tools/force_mode_zh.py     （新游戏难度/模式向导）
8. python tools/force_randomizer_zh.py
9. python tools/force_names_zh.py    （官方人名地名）
10. python tools/force_trainer_class_zh.py
11. python tools/patch_battle_names_zh.py（宝可梦/招式/特性固定表）
12. python tools/patch_items_zh.py    （827 个道具名 + 800 条说明）
13. python tools/diff_guard.py       （须 OK；PokemonSioInfo 区不变）
14. copy work\cn_build.gba out\quetzal_084_cn.gba

字库说明
--------
vendor/Pokemon_GBA_Font_Patch-main 内的 armips 2023 版
Windows 构建会先由 tools/prepare_armips_source.py 展平 include，生成文件不入库。
Quetzal 适配地址见 fontpatch/include/text.h
  CharRead hook  0x0800596C（真 RenderText@588C；勿用死副本 21CC68）
  AfterRead join 0x08005978
  CopyGlyph join 0x08005D34
  Hack CODE     0x08EB9878
  Hack FONTS     0x09D9B5A8
  开始菜单强制汉化：tools/force_ui_zh.py（图鉴/宝可梦/背包/导航/保存/选项/退出）
  GetStringWidth：暂未钩；对话若换行异常再补 Quetzal 专用宽度钩

注意
----
- 译文为词表+短语表初翻；开始菜单/系统短语已强制中文；长对话仍偏机翻，可继续润色 locale。
- 主屏副屏必须使用字节级同一 ROM。
- 换 ROM 后若仍见旧字：清应用数据，或 bump MbRomBootstrap.ROM_PACK_VERSION。
- 不要把 archive/ 里的一次性脚本堆回 tools/；新译文优先写 locale。
