格查尔 0.8.4 — 发现未汉化内容后如何补
======================================

现象
----
游戏里仍看到英文 / 半中半英 / 错译（如 lives→「还活着」）/ 截断乱码。


一、先判断：是不是「旧 ROM」
----------------------------
主屏中文、副屏英文 → 多半不是漏翻，是副屏进程握着旧 ROM。
处理见 DUALSCREEN.txt（force-stop、重拉副屏、同文件硬链接）。

确认当前 out/quetzal_084_cn.gba 已热更，且两端指纹一致后再查漏翻。


二、拿到英文原文
----------------
1. 游戏里抄下完整英文（含换行、人名大小写）。
2. 或 log / 截图 OCR。


三、在母盘里定位 offset
----------------------
在 QuetzalCN_084：

  python -c "..."
或写小脚本：

  from pathlib import Path
  from gen3_charmap import encode_plain, decode_bytes
  golden = Path('golden/en_0.8.4.gba').read_bytes()
  cn = Path('out/quetzal_084_cn.gba').read_bytes()
  core = encode_plain("Town Map")[:-1]   # 不要最后的 FF
  i = 0
  while True:
      j = golden.find(core, i)
      if j < 0: break
      eos = golden.find(b'\xff', j)
      print(hex(j), decode_bytes(golden[j:eos+1]))
      print('  CN now:', decode_bytes(cn[j:cn.find(b'\xff', j)+1]))
      i = j + 1

注意：
  - 同一句可能有多份拷贝（如多句 DAD）；每处都要查 CN 是否已改。
  - 「CN now」仍等于英文 = 漏翻或写失败。
  - 「CN now」已是中文但游戏仍英文 = 游戏读的是别的指针拷贝 / 旧 mmap。


四、扫描残留英文（批量）
------------------------

产出多在 work/（若被 gitignore，跑完立刻看控制台）。

历史更大扫描在 archive/oneshot/（scan_remain_all 等），需要时拷回 tools/ 再跑。

1. 不要用「与黄金完全相同才补」的扫描（会漏掉半翻）。
2. 用「仍含大量拉丁字母」条件扫（fill_latin_* 已归档，可参考）。
3. 错译：改 locale 或 gtrans_cache.json 后重 apply；
   关键句手写覆盖 ROM（并写回 locale 以免下次冲掉）。
